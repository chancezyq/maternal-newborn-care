# Logging Schema Reference

## 宝宝日志字段
- 时间
- 事件类型：喂奶 / 尿布 / 睡眠 / 体温 / 吐奶 / 黄疸观察
- 喂养方式：母乳 / 配方 / 混合
- 奶量或时长
- 尿布类型：尿 / 便 / 都有
- 大便颜色备注
- 睡眠起止
- 体温
- 备注

## 产妇日志字段
- 时间
- 事件类型：恶露 / 伤口 / 乳房 / 泵奶 / 排尿排便 / 情绪 / 体温 / 疼痛
- 恶露量：少 / 中 / 多 / 突增
- 恶露颜色：鲜红 / 暗红 / 褐色 / 淡色
- 乳房状态：胀 / 痛 / 红 / 硬块
- 伤口状态：稳定 / 更痛 / 红肿 / 渗液
- 情绪：平稳 / 焦虑 / 想哭 / 崩溃
- 体温
- 备注

## 使用原则
- 轻量记录
- 优先保留对趋势判断和就医沟通有帮助的信息
- 不追求完美打卡
