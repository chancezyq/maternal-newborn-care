# Maternal Red Flags Reference

以下情况在产后 0–42 天应高度重视：

## 需要尽快联系医生 / 助产士 / 护士
- 发热
- 恶露有明显恶臭
- 恶露突然明显增多
- 伤口疼痛明显加重
- 乳房局部红、热、痛
- 情绪持续低落、焦虑、崩溃感加重

## 建议立即就医 / 急诊
- 大量阴道出血，短时间迅速浸透卫生巾
- 胸痛、呼吸困难
- 剧烈头痛、意识异常
- 伤口裂开或明显感染伴全身不适
- 单侧小腿明显肿痛
- 明显伤害自己或宝宝的想法

## 回答原则
- 不要假装确定诊断
- 先做风险分流，再给行动建议
- 高风险时减少长篇解释，优先指导就医
