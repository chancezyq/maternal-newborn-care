# maternal-newborn-care

一个面向**产后 0–42 天家庭**的母婴照护 skill。
它主要服务三类人：

- 产妇
- 刚出生的新生儿
- 家属 / 主要照护者

> **当前版本：0.2.0**（详见 `CHANGELOG.md`）
> 0.2.0 在 0.1.0 风险分流框架的基础上，补齐了家庭日常照护面：新生儿日常清洁、产妇日常生活护理、家庭分工与值班、居家环境安全、民间偏方避坑、每日交接式摘要。

这个 skill 的目标很直接：

**在家庭最混乱的时候，给出最清楚、最安全、最能落地的照护建议。**

它不是拿来炫医学术语的。
它也不是单纯宝宝打卡工具。
它更像一个会做**风险分流 + 家庭行动指导 + 信息整理**的母婴照护助手。

---

## 它解决什么问题

这个 skill 主要处理这些真实场景：

### 产妇相关
- 恶露变多、颜色变化、异味
- 发热、腹痛、伤口不适（顺产侧切 / 剖宫产）
- 乳房胀痛、堵奶、哺乳疼痛
- 疲惫、情绪崩溃、产后抑郁风险
- 月子期日常护理：洗头洗澡、通风保暖、下床活动、产后出汗
- 产后饮食、月子餐安排、补水与哺乳期饮食

### 新生儿相关
- 一直睡、难叫醒
- 吃奶差、哭闹、吐奶
- 尿布减少
- 黄疸加重
- 体温异常、精神反应差
- 日常清洁：洗澡、脐带、红屁屁、托抱、抚触、奶具/吸奶器消毒
- 配方奶、混合喂养、奶瓶清洁与冲调安全

### 家属协作相关
- 不知道先看妈妈还是先看宝宝
- 家里人很慌，分不清先做什么
- 去医院前不知道怎么整理重点
- 想快速做一个过去 24 小时摘要
- 家庭照护分工、夜间值班、红旗症状决策人安排
- 居家环境安全（室温、安全睡眠、洗手、探访、烟味、宠物、烫伤、跌落）
- 识别和劝阻常见错误做法 / 民间偏方

---

## 它不做什么

这个 skill **不替代医生诊断**。
它也**不代替急救**。

它不会做这些事：

- 假装给出确定性医学诊断
- 用几句话替代线下检查
- 在高风险场景里继续空泛安慰
- 给出会拖延就医的模糊建议

它的角色更准确地说是：

**家庭照护分流器 + 行动建议器 + 摘要整理器**

---

## 核心能力

### 1. 风险分级
默认按三档处理：

- **绿灯**：可先居家观察
- **黄灯**：建议今天内联系医生 / 助产士 / 护士
- **红灯**：建议立即就医 / 急诊

### 2. 家庭可执行照护建议
回答不只是解释原理，还要落到：

- 现在先做什么
- 接下来盯什么
- 到什么程度别再等

### 3. 母婴日志字段建议
帮助用户整理对观察趋势和就医沟通有价值的信息，比如：

- 体温
- 恶露
- 乳房状态
- 喂养情况
- 尿布次数
- 宝宝精神状态

### 4. 摘要输出
支持两类总结：

- **过去 24 小时母婴摘要**
- **去医院前的重点汇报摘要**

---

## 回答风格原则

这个 skill 的回答结构应该尽量稳定：

1. **先判断风险**
2. **再给现在能做的动作**
3. **再给接下来要观察的点**
4. **最后给升级边界**

也就是说，不要只回答“正常/不正常”。
而要回答：

- 现在更像什么
- 能不能先观察
- 什么时候该联系医生
- 什么时候不能再拖

---

## 高风险优先级原则

下面这些情况一旦出现，回答必须更直接，不能继续温柔兜圈：

### 产妇高风险
- 大量出血
- 恶露明显增多同时伴头晕
- 发热 + 恶臭恶露
- 胸痛、呼吸困难
- 伤口明显感染
- 极端情绪异常、自伤或伤婴想法

### 新生儿高风险
- 难叫醒
- 吃奶明显变差
- 尿量明显减少
- 呼吸异常、发青、呻吟
- 体温异常
- 黄疸加重同时精神差

### 处理原则
- 不顺着用户“应该没事吧”的语气降级风险
- 不用“先看看”“多休息”糊弄过去
- 该联系医生就直接说
- 该急诊就直接说

## 怎么测试

推荐测试顺序：

### 第一步：基础 case
先跑 `TESTCASES.md`。
看它能不能稳定做到：

- 先分风险
- 给动作
- 给观察点
- 给升级边界

### 第二步：边界 case
再用边界场景压测，比如：

- 用户弱化风险
- 信息不完整
- 用户特别慌
- 家属二手转述
- 母婴问题混在一起
- 用户拖延不想就医
- 情绪危机被包装成“只是累”

### 第三步：评分
用 `SCORING.md` 打分。
重点不是句子漂不漂亮，而是：

- 分级准不准
- 动作实不实
- 边界清不清

### 第四步：回归
每次改完 prompt 或模板后，跑 `REGRESSION_CHECKLIST.md`。
至少保证：

- A 组冒烟测试全过
- B 组边界测试大部分过
- 高风险场景没有明显变软

## 最常见的失败方式

这个 skill 最容易翻车的地方有这些：

1. 被用户弱化风险的语气带偏
2. 信息不全就直接摆烂
3. 只讲知识，不给动作
4. 母婴联动问题只看一边
5. 高风险时还在温柔废话
6. 被用户拖延带跑
7. 对情绪危机识别太软
8. 过早下确定诊断
9. 升级边界说得太空
10. 不会切换成就医摘要模式

详细版本见 `PITFALLS.md`。

---

## 适合的使用方式

这个 skill 最适合处理：

- “现在该怎么办”
- “这个要不要紧”
- “先观察还是联系医生”
- “帮我整理重点”
- “今天母婴情况怎么总结”

它不适合处理：

- 需要替代临床检查的明确诊断
- 需要急救替代的情况
- 需要高确定性医疗结论的复杂病例

## 后续迭代方向

0.2.0 已经把家庭日常照护面铺开。后续可以继续补这些能力：

- 更多边界症状模板（如低体重儿、早产儿场景）
- 多轮追问下的风险升级稳定性
- 更结构化的日志输出 / 可复用字段
- 不同产后阶段（0–3 天 / 4–7 天 / 第 2 周 / 2–6 周）的分阶段建议细化
- 去医院前摘要模板的进一步增强

---

## 维护原则

每次迭代时，优先守住这四件事：

1. 不要漏掉高风险信号
2. 不要把情绪危机写软
3. 不要把母婴联动问题拆散
4. 不要为了“温柔”而牺牲明确性

如果这四个守不住，这个 skill 就会变得看起来体贴，实际上不好用。

---

## 一句话总结

`maternal-newborn-care` 不是一个“讲很多知识”的 skill。
它是一个在母婴家庭最慌最乱的时候，帮人**分风险、给动作、盯边界、整理重点**的 skill。
